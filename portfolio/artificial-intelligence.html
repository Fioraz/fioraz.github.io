Salary Prediction Model Using Machine Learning

I created this project to learn how machines can use past data to make predictions, in this case, estimating someone’s salary based on their years of experience. I built and tested different AI models to see which ones gave the most accurate results.

I also focused on using data in a fair and responsible way. That meant checking for bias in the information and the predictions, so the system wouldn’t unfairly favour or disadvantage anyone. This project helped me grow both my technical skills and my understanding of ethical, responsible AI.
